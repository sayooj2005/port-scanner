# port-scanner
Multi-threaded port scanner with service version detection for network security testing.

## Features

- Scan single IP, multiple IPs, CIDR ranges, IP ranges
- Service version detection (HTTP, SSH, FTP, MySQL, SMTP, POP3, IMAP)
- Multi-threaded for fast scanning
- Colorful CLI output
- Save results to file

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/port-scanner.git
cd port-scanner
python3 port_scanner.py
